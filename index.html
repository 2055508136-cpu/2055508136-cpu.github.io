Read · Collect · Write

个人学习工具 · Windows 本地运行

把时事阅读，
变成写作积累。

从有真实出处和使用许可的英文文章中，整理适合六级学习的原文、短语、句型与中文思考，便于手写摘抄和复习。

CET6 Reader is a local Windows application for personal English reading and writing practice. It creates study notes from recent, licensed articles and can deliver them through Gmail after the account owner grants permission.

How it works

从文章到一页笔记

01

查找近期文章

优先选取近 30 天发表的科技、教育、经济、环境与社会评论，核对链接、作者、日期和原文使用许可。

02

整理表达，检查来源

选取适合手写的英文段落，借助模型解释短语、分析论证与原创仿写，再检查原句和来源是否一致。

03

本地保存，按需投递

笔记保存在个人电脑。Gmail 投递需本人 OAuth 授权及发送许可；计划频率、收件人和模型预算均可修改。

Google access

只申请发送权限

连接 Gmail 时，CET6 Reader 仅申请 gmail.send，用于发送本人选择的学习笔记。程序不读取收件箱，不索取 Google 密码。

Only the Gmail send permission is requested. The application does not read incoming email or send Google credentials to the language model. This website is an informational site; Google authorization takes place through the local application and Google's own sign-in page.
