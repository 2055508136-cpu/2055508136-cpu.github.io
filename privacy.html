1. 项目与用途 / Purpose

CET6 Reader 是个人使用的 Windows 英语学习工具，由本页所列联系邮箱的项目维护者维护。程序检索公开且许可适当的近期文章，生成并保存阅读笔记，可在本人授权后通过 Gmail 向配置的收件人发送笔记。本网站介绍该应用及其数据处理方式，不提供在线注册或在线邮箱授权。

CET6 Reader runs locally on the user's Windows computer. It prepares personal study notes and optionally sends those notes to the recipient configured by the user. The project has no application server that collects users' mailboxes or credentials.

2. Google 授权、访问与用途 / Google data

  • 权限：仅请求 https://www.googleapis.com/auth/gmail.send，用于代表本人提交学习邮件。程序不请求读取、删除、修改收件箱邮件或联系人资料的权限。
  • 授权信息：程序接收 Google 发放的访问令牌和刷新令牌，用于发送及刷新授权；保存桌面 OAuth 客户端信息。Google 密码与验证码由本人在 Google 页面输入，本程序不接收这些信息。
  • 邮件数据：发送时向 Gmail API 提交配置的收件地址、标题和笔记的 HTML/纯文本正文；保存 Gmail 返回的邮件 ID，以记录结果和防止重复提交。发件和收件地址由本人在本机配置，程序不通过读取邮箱获取它们。
  • 用途限制：Google API 信息仅用于本人授权的邮件发送、授权维护与发送状态记录。不会出售这些信息、用于广告或信用评估，也不会用其训练模型。维护者不会远程读取用户邮件；排障需要分享具体记录时，由本人决定是否提供。

The application uses only the Gmail send scope. It stores OAuth credentials and the message IDs returned by Gmail to support authorized delivery and local status tracking. It does not retrieve inbox messages, contacts or Google profile data, and does not sell Google data or use it for advertising or AI training.

CET6 Reader follows the Google API Services User Data Policy and its Limited Use requirements when using or transferring information received from Google APIs.

从 Google API 获得的信息，其使用与转移遵守上述政策及 Limited Use（受限使用）要求。

3. 模型与其他服务 / Processing and sharing

  • 模型提供商：当前配置使用 DeepSeek 官方 API，接收所选公开文章的标题、出处、英文摘录、生成要求与待审核的语言分析。切换提供商后，应核对该服务的数据处理政策。Gmail 的令牌、OAuth 客户端密钥、Google 密码及 Gmail 返回的邮件 ID 不会进入模型提示。
  • 邮件投递：本人同意发送后，邮件正文及投递地址交给 Google 处理，并经邮件系统交给指定收件人的服务商。笔记可能包含本人在本地修改的内容，应在发送前审阅。
  • 来源访问：文章网站接收普通网页或 RSS 请求，可能按照各自政策记录网络信息。本程序尊重来源许可和访问限制。
  • 转移范围：与 Google API 有关的数据转移限于上述本人授权的邮件投递功能；其他适用的法律或安全处理情形受 Google 数据政策约束。程序不向说明网站上传学习记录或凭据。

The configured model provider receives public article excerpts and study instructions for generation and review. OAuth credentials and Google API response data are excluded from model requests. Authorized email content and delivery addresses are processed by Google and the recipient's mail provider. The informational website does not receive local notes or account credentials.

4. 本地保存、保留与安全 / Storage and retention

API 密钥、Gmail 令牌及令牌中包含的客户端信息使用 Windows 当前用户的 DPAPI 加密后保存在本机；访问第三方官方接口使用 HTTPS。程序避免把密钥、令牌和 API 错误响应正文写入日志。

配置中的邮箱地址、文章缓存、笔记、错误记录、发送状态及模型用量账本保存在本地普通文件或 SQLite 中，这些学习及配置文件没有全部加密。应保护 Windows 账号和设备访问权限，并谨慎备份或共享项目目录。

本地记录默认保留至本人主动清理，没有云端集中备份或自动远程收集。刷新令牌保留至重新授权、删除或 Google 撤销；本地用量账本用于执行已批准的预算限制，不能通过删除账本绕过费用上限。

Sensitive credentials are protected at rest with Windows user-level DPAPI. Notes, addresses in settings and local history are ordinary local files, not all encrypted. Records remain on the computer until the user removes them. No security measure guarantees protection if the user's account or device is compromised.

5. 撤销授权、停止与清理 / Your controls

  1. 在本机暂停自动任务及发送，避免清理期间继续运行。
  2. 通过 Google 账号的第三方连接管理页面 撤销该项目的访问权限。撤销后程序无法继续使用刷新令牌取得发送授权。
  3. 如需清理，在确认任务已停止后，删除本地受保护的 Gmail 令牌；按 README 清理不再需要的笔记、缓存和相关记录。必要的用量记录应保留到对应预算周期结束，或同时禁用模型调用。
  4. 已发送邮件的副本需由本人或收件人在各自邮箱中处理；本程序没有删除云端邮件的权限。第三方服务保存的数据按其各自政策和账号管理入口处理。

You can pause delivery, revoke the application's access in your Google Account, and remove local credentials and study files. Revocation does not delete previously delivered messages. The application cannot delete mailbox data because it has no mailbox-management permission.

6. 说明网站 / Informational website

本说明网站由 GitHub Pages 托管，只提供静态介绍页面。页面不加入广告、分析脚本、表单或登录功能，也不主动设置跟踪 Cookie。GitHub 作为托管服务商会为安全目的记录访问者 IP 地址，详见 GitHub Pages 数据收集说明 及 GitHub 隐私声明。

These static pages add no analytics, advertising, forms or tracking cookies. GitHub may log visitors' IP addresses for security as the hosting provider. Website source files and the contact address are public; local application data and secrets are not part of the website.
